# edge/app: the MUSTER app page

Plain HTML, CSS and JavaScript with no build step, served by the Gatekeeper at `/app/` (see `gatekeeper/api/start_app.ps1`). It uses Arjo's scanner code from `edge/scanner` (`cac_parse.js` and the bundled zxing-wasm).

- Talks only to the Gatekeeper on the same address. Strict CSP (`connect-src 'self'`, no inline scripts).
- A scanned card is parsed on the device. Only the 10-digit ID goes to the Gatekeeper, which hashes it with a key this page never holds. The raw barcode string is dropped after parsing.
- Tokens are kept in memory only. Nothing is stored in the browser.
- The page shows what the API returns. It does not work out points, totals or grades.
- `demo_tokens.js` is generated by the server and only filled in for the laptop itself (the admin token for Register and the demo gate token).
- Without a camera, each scan box has a "paste a test barcode" fallback for the synthetic cards.

Older Edge files (`barcode_scan.py` and the other READMEs) are from before the live API and are out of date.
